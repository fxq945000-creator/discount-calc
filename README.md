# 折扣计算器（划算测算工具）

帮用户快速测算“买东西到手价”，判断划不划算：输入商品价格与各类促销，立刻算出**到手价、省了多少、省了百分之多少**，并给出**凑单建议**与**会员回本**分析。

纯前端静态网页，响应式 + PWA（手机/电脑通用，可“添加到主屏幕”当 App 用），无后端、无账号、数据手动输入、合规安全。

## 功能

- 🛒 商品录入：原价、数量、会员价、多件多折（第二件半价 / 买 N 免 1 / 满 M 件打折）
- 🏷️ 促销：满减/满折（店铺/平台）、优惠券、会员折扣+年费回本、红包/积分/淘金币抵扣、返现
- 📊 实时结果：到手价、省了多少、省率、逐层优惠明细（标注每一步计费基数）
- 🧮 凑单建议：差多少到门槛、加购是否值得
- 💎 会员回本：本次会员省多少、几次回本
- 🕘 本地历史（localStorage）、🔗 URL 分享、📱 可安装 PWA

## 本地运行

```bash
npm install
npm run dev        # 开发预览 http://localhost:5173
npm run build      # 产物输出到 dist/（纯静态）
npm run preview    # 本地预览构建产物
npm run test       # 运行计算引擎单元测试（Vitest）
```

## 部署（任选其一，均为静态托管）

- **GitHub Pages / 任意静态空间**：把 `dist/` 目录整体上传即可。
- **Vercel / Netlify**：连接仓库，构建命令 `npm run build`，发布目录 `dist`。
- 无需服务器、无需数据库。

## 安装为 App（PWA）

用手机/电脑浏览器打开已部署的网址 → 地址栏或菜单选“添加到主屏幕 / 安装”，即可像原生 App 一样离线使用。

## 计算口径（重要）

折扣按以下顺序叠加，明细面板逐步可见可核对：

1. 会员价 / 会员折扣 → 2. 单品多件多折 → 3. 店铺满减/满折 → 4. 优惠券 → 5. 红包/积分抵扣 → 6. 返现（不计入到手价，作为实际收益）

满减/券门槛默认按“商品金额（折后、券前）”计算；可在「规则」里切换平台预设（淘宝/京东/拼多多/自定义）。各家平台规则略有差异，工具以“明细可见、可改”为原则，不追求覆盖所有边界。

## 目录结构

```
src/
  engine/        核心计算引擎（discountEngine.ts）+ 规则预设 + 单测
  components/    商品/促销/结果/历史 等 UI 组件
  store/         状态与本地存储
  utils/         金额格式化、分享链接
```
